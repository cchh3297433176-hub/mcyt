# 主播掌机 (Streamer Console)

专为主播 **咩咩** 打造的定制私密手持生态与沉浸式掌机系统。系统采用微信原生视觉语言（纯白圆角卡片、极浅灰底色、微绿点缀与极简设计），提供兼顾日常沟通、互动娱乐、同人创作与音乐聆听的一体化掌上终端。

---

## 🌟 核心特性与应用矩阵

### 1. 💬 聊天中心 (Chat)
- **原生沟通质感**：沉浸式单聊、多人群聊与朋友圈流式动态。
- **自定义同伴驱动**：100% 联动自主创建与持久化的真实联系人，赋予独特人设、羁绊与专属反应。
- **个性装扮与气泡**：支持高清自制头像框池、个性聊天气泡底图微调与尺寸适配，全面支持 IndexedDB 扩容存储。
- **丰富多态交互**：支持战报总结、多媒体互动卡片与音乐卡片一键私聊沉淀。

### 2. 🎵 微音 (WeMusic)
- **网易云经典红黑视觉**：沉浸式黑胶自转动效、时间轴精准对齐的高清歌词高亮与双语翻译切换。
- **发现与角色歌单**：
  - 每日私享雷达推荐，接入 Fisher-Yates 真正随机洗牌算法换一批热门热歌。
  - 联动通讯录自建角色性格，增量刷新与轮询生成角色专属音乐主页与私人心境歌单。
- **双轨登录中枢**：支持安全扫码登录（免风控验证）与手机验证码通道。
- **全屏悬浮球与胶囊控制**：全局手势任意拖拽、智能贴边吸附微缩黑胶，支持循环模式切换（列表循环 / 单曲循环 / 随机播放）。
- **个性主页与换装**：支持自定义主页背景封面与个性头像框无缝佩戴。

### 3. 🎮 游戏大厅 (Game Lobby)
- **经典棋牌切磋**：内置斗地主、五子棋、象棋等多款离线即开与云端仲裁棋牌游戏。
- **同伴入座陪玩**：支持自建角色入座对决、实时局内 Whisper 对白互动。
- **战报记忆沉淀**：切磋结束后生成带角色署名的详细战报，一键沉淀进单聊历史。

### 4. 📚 同人文库 (Archive of Our Own · AO3)
- **同人小说阅读与共创**：针对移动端手持体验优化的 AO3 文库沉浸视口。
- **双向羁绊联动**：角色根据作品情节展开真实反应，支持私聊分享同人佳作。

### 5. 🔮 塔罗星轨 (Tarot)
- **复古星象交互**：专属 4 格宽桌面塔罗小组件与全屏占卜视口。
- **运势启示推演**：支持单张与三张牌阵，轻触自转翻开牌面，生成今日运势与灵性启示。

### 6. 🧠 忆海 (Rememori)
- **长期记忆中枢**：基于向量检索与证据链沉淀的角色记忆档案，守护长久羁绊。

---

## 🛠️ 技术架构亮点

- **前端视口**：现代模块化原生 JavaScript + 响应式移动端流式布局，安全区顶部避让（Safe Area Insets）防遮挡。
- **持久化契约**：
  - 高频轻量状态使用 `localStorage`。
  - 海量文本、高清头像框底图、动图气泡素材与聊天历史全面接入 **IndexedDB (localForage)**，杜绝 5MB 硬配额溢出。
- **生态协同**：子模块间严格遵循单向数据流与唯一权威数据源规范，保障各 App 与主系统平滑解耦。

## 📱 桌面与外壳交互

- **真实手机感知**：智能时钟、电量状态感知、网络及蓝牙状态栏。
- **桌面双页平滑滑屏**：支持应用网格、日历日程、便签待办与微音桌面黑胶小组件自定义拖拽换位。
- **排版微调模式**：支持全桌面各层级自由手拖微调并永久持久化记忆。
